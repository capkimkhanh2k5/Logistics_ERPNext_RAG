Cấu hình Kết nối AI & Backend Tools

Giao diện frontend đã sẵn sàng 100%. Bạn có thể kết nối bất kỳ mô hình AI (Gemini, Claude, OpenAI) hoặc các Python Tools của bạn qua các cổng hook bên dưới.

Cách gắn kết logic AI & Tools của bạn vào giao diện:
// Trong file JS của bạn hoặc console, chỉ cần override hàm:
window.LogisticsChatbotBridge.onSendMessage = async function(userMessage, history, context, callbacks) {
    // 1. Gửi tin nhắn đến LLM / API của bạn:
    // 2. Khi LLM đang suy luận:
    callbacks.onThinking("Đang tra cứu cơ sở dữ liệu Trade Case...");

    // 3. Khi AI gọi công cụ (Tool Call):
    callbacks.onToolCall("get_case_cost_summary", { case_id: "IMP-2026-001" }, { actual_cost: 18350.0 });

    // 4. Khi nhận luồng phản hồi (Streaming chunk):
    callbacks.onStreamChunk("Lô hàng **IMP-2026-001** hiện có...");

    // 5. Khi hoàn tất:
    callbacks.onComplete("Nội dung markdown đầy đủ hoàn chỉnh.");
};
